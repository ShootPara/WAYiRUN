# 1 Security policy

## 1.1 Supported version

Security fixes are considered for the current Version 1.0 source on `main`.

## 1.2 Reporting a vulnerability

Report suspected vulnerabilities privately to `unopenedparachute@gmail.com`.

Do not post credentials, API keys, authentication tokens, private run data, precise routes, personal exports, signing material or exploitable details in a public issue.

Include a concise description, affected component, reproduction conditions and potential impact. Use synthetic data whenever possible.

## 1.3 Sensitive material

WAYiRUN does not require contributors to submit user OpenAI keys, Cloudflare credentials, Google secrets, signing keys or private database exports. Such material must remain outside Git and should be rotated if accidental exposure is suspected.

Public OAuth client IDs and public resource identifiers used by the applications are configuration identifiers, not authentication secrets. Passwords, private keys, Worker secrets, session credentials and user API keys are sensitive.

## 1.4 Disclosure

Allow reasonable time to investigate and prepare a correction before publishing vulnerability details. No bug-bounty or paid-reward program is currently offered.
