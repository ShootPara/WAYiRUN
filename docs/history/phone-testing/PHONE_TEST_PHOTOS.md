# 1 Photos and achievements phone check

## 1.1 Install

Install WAYiRUN-2026-09-19_06-36-20_EDT.apk over the current app. Do not uninstall. Existing runs, sign-in and settings should remain.

## 1.2 After your run

1. Finish and check coaching/achievements as planned. Dismiss the celebration to reach the saved summary.
2. Use the photo button at the top. Take Photo opens your camera; use its front/rear switch. Choose Existing Photo and Skip are also available.
3. Select time, distance, pace and (when recorded) route overlays. Verify preview, Retake and Keep Photo. Route gaps should remain gaps.
4. Make this run public starts checked, as requested. Uncheck it to keep the photo private. Keep saves locally; cloud/publication waits for run sync and connectivity.
5. Try Save photo (Android file destination picker) and Share photo. After cloud sync, Share run link appears for public photos.
6. Refresh the development website and open the run. Verify the image and shared link. Open a public link while signed out; only that run should appear. A private photo should have no shared link.

## 1.3 Optional recovery check

Keep a photo offline, reopen it, reconnect and allow sync. A replacement leaves the earlier cloud version in place until the replacement syncs; then the old public link is revoked. Cancel/Skip does not replace a kept photo. Do not delete a real run just to test cleanup; automated tests cover deletion and account isolation.

## 1.4 Scope

Images are compressed JPEGs, up to 1600 pixels and 1 MB. Source image metadata is not uploaded. Saved/exported/shared copies are independent of later run deletion. Photos on another phone are available from the website; automatic image restoration to a new phone is not implemented.
